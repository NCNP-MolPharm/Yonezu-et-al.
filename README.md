# Yonezu-et-al.

Analysis code for Yonezu et al.

Code used in 'Circulating low-density lipoprotein promotes perivascular cell proliferation and scar formation following spinal cord injury' This repository contains the code used for the following data analyses.

1. EBseq for mouse RNA-seq
2. DESeq2 for human RNA-seq
3. Comparison of mouse and human RNA-seq
