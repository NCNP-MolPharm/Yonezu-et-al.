# Yonezu-et-al.

Analysis code for Yonezu et al.

Code used in 'Circulating low-densit lipoprotein promotes fibrotic scar formation and prevents functional recovery after spinal cord injury' This repository contains the code used for the following data analyses.

1. Creating count read file
2. EBseq for mouse RNA-seq
3. DESeq for human RNA-seq
4. Comparison of mouse and human RNA-seq
